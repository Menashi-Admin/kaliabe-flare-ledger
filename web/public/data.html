Source registry

Every source is checked by scripts/validate_sources.py. It records whether the source is reachable, its version or vintage, a SHA-256 checksum of the fetched bytes and its licence, and writes docs/DATA-SOURCES-REGISTRY.md. It exits non-zero if any source is unreachable, so a stale source shows up instead of failing silently.

Seed data

The current snapshot is derived from the World Bank GFMR individual-flare-site dataset (Nigeria subset), committed to this repository as data/gfmr_nigeria_sites_seed.json (476 unique sites, 2012–2025). The live digest (one row per site-year; volumes in million m³, with bcm and MMscfd) downloads from /api/digest.csv; a static snapshot built from the committed seed is at kaliabe-flare-digest.csv.

Live ingestion

Live thermal (KFL-M 1.3). A GitHub Action (.github/workflows/live-thermal.yml) pulls the NASA FIRMS VIIRS 375 m regional files every day, matches detections to ledger sites within 1 km, and commits a rolling 30-night summary that the API reads. The archive verdicts still come from GFMR annual volumes; the live check adds “is it burning now?”. Raw per-night VIIRS Nightfire (VNF) files at eogdata.mines.edu need an EOG login and are not fetched.

Security. ACLED point events need a myACLED account. Until that exists, the security block uses ACLED's public LGA-level monthly aggregates; per-site radius counts are marked pending.
